Specyfikacja usługi UUG

Usługa UUG (Usługa Usług Geokodowania) umożliwia wyszukiwanie współrzędnych oraz obiektów przestrzennych na podstawie podanych kryteriów adresowych, kilometrażu dróg krajowych, identyfikatorów przejazdów kolejowych, a także bazy państwowego rejestru nazw geograficznych (PRNG) i słowników TERYT.

Metody wywołania usługi (Endpoints)

API obsługuje zapytania typu GET. Poniżej znajdują się dostępne metody strukturyzacji zapytań:

1. Wyszukiwanie i lokalizacja adresów

GET https://services.gugik.gov.pl/uug?request=GetAddress&address={address}

2. Odwrotne geokodowanie (Adres na podstawie współrzędnych)

GET https://services.gugik.gov.pl/uug/?request=GetAddressReverse&location={location}&srid={srid}

3. Lokalizacja obiektów liniowych i punktowych (Kilometraż dróg, Kolej, PRNG)

GET https://services.gugik.gov.pl/uug?request={request}&location={location}

4. Zapytania słownikowe i strukturalne (TERYT / SIMC)

GET https://services.gugik.gov.pl/uug?request={request}&[parametry_slownika]

Konsola testowa API

Wybierz metodę, uzupełnij wymagane parametry i przetestuj działanie usługi UUG na żywo. Odpowiedzi JSON zostaną automatycznie sformatowane.

Parametry zapytania (Query Parameters)

        

            
                

                    Parametr
                    Typ
                    Opis
                    Wartości / Format / Przykłady
                

            
            
                

                    request
                    string wymagany
                    Określa rodzaj operacji oraz poszukiwanego obiektu słownikowego lub przestrzennego.
                    
                        GetAddress – wyszukanie punktu adresowego

                        GetAddressReverse – odwrotne geokodowanie z WKT

                        GetRoadMarker – lokalizacja słupka kilometrowego drogi

                        GetLevelCrossing – wyszukanie przejazdu kolejowego

                        GetLocation – obiekty z Państwowego Rejestru Nazw Geograficznych

                        GetCity – słownik miejscowości dla gminy

                        GetStreet – słownik ulic w danej miejscowości

                        GetAddresses – wykaz punktów przy ulicy lub w miejscowości
                    		
                

                

                    address
                    string
                    Dowolna, tekstowa postać szukanego adresu (stosowana przy GetAddress).
                    
                        • Miejscowość, Ulica Numer (np. Marki, Andersa 1)

                        • Miejscowość Numer (np. Królewskie Brzeziny 13)

                        • Miejscowość, Ulica

                        • Miejscowość
                    		
                

                

                    location
                    string
                    Wielofunkcyjny parametr definiujący geometrię, opis lub unikalny kod obiektu.
                    
                        • Geometria w zapisie WKT: POINT(X Y) (np. POINT(21.020 52.229))

                        • Droga i słupek: [Droga] [Słupek] lub samo [Droga] (np. 714 10)

                        • Identyfikator kolejowy (pełny lub min. 3 znaki): (np. 001 018 478)

                        • Nazwa obiektu z rejestru PRNG: (np. Las Mierzei)
                    		
                

                

                    srid
                    integer
                    Układ odniesienia przestrzennego EPSG stosowany do interpretacji geometrii wejściowej.
                    Najczęściej stosowane: 4326 (WGS 84 dla GPS) lub 2180 (PUWG 1992).
                

                

                    teryt
                    string
                    Krajowy kod identyfikacyjny podziału terytorialnego dla jednostki nadrzędnej (gminy).
                    6-cyfrowy identyfikator TERYT (np. 141207)
                

                

                    simc
                    string
                    Unikalny identyfikator miejscowości pochodzący z rejestru TERYT.
                    7-cyfrowy kod SIMC (np. 0668956 lub 0002750)
                

                

                    ulic
                    string
                    Systemowy identyfikator nazwy konkretnej ulicy powiązany z bazą TERYT.
                    5-cyfrowy kod ULIC (np. 00470)
                

            
        

    


    

        Uwagi techniczne i parametry zaawansowane:
        
    
            
  • Dokładność dopasowania (Parametr accuracy): Domyślnie przyjmuje wartość 0.6. Może być przekazywany opcjonalnie w zakresie od 0.5 do 1.0 w celu sterowania dokładnością dopasowania adresu tekstowego do wzorca bazowego.
    • 
            
  • Ścisły numer porządkowy (Parametr exact_number): Domyślnie przyjmuje wartość 1. Nakazuje usłudze zwrócenie wyłącznie tych wyników, w których przypisany numer porządkowy pokrywa się idealnie z szukaną frazą.
    • 
            
  • Zwracane dane: Rezultaty zapytań usługi geokodowania zwracają współrzędne punktu geometrycznego szukanego obiektu lub powiązane listy obiektów słownikowych wraz z ich metadanymi rejestrowymi w formacie JSON.

Przykłady wykorzystania


        
1. Wywołania usługi dotyczące adresów (Geokodowanie i Odwrotne geokodowanie)

        
        
• Miejscowość, Ulica Numer

        https://services.gugik.gov.pl/uug?request=GetAddress&address=Marki, Andersa 1

        
• Miejscowość Numer (Miejscowości bez struktur ulic)

        https://services.gugik.gov.pl/uug?request=GetAddress&address=Królewskie Brzeziny 13

        
• Miejscowość, Ulica (Wyszukanie osi/centrum danej ulicy)

        https://services.gugik.gov.pl/uug?request=GetAddress&address=Marki, Andersa

        
• Miejscowość (Lokalizacja ogólna punktu miejscowości)

        https://services.gugik.gov.pl/uug?request=GetAddress&address=Marki

        
• Wyszukiwanie punktu adresowego w pobliżu współrzędnych geograficznych (GetAddressReverse)

        https://services.gugik.gov.pl/uug/?request=GetAddressReverse&location=POINT(21.020 52.229)&srid=4326

        
2. Wywołanie usługi dotyczące kilometrażu dróg i kolei

        
        
• Oznaczenie drogi krajowej i słupek kilometrowy

        https://services.gugik.gov.pl/uug?request=GetRoadMarker&location=714 10

        
• Samo oznaczenie drogi

        https://services.gugik.gov.pl/uug?request=GetRoadMarker&location=714

        
• Identyfikator przejazdu kolejowego

        https://services.gugik.gov.pl/uug?request=GetLevelCrossing&location=001 018 478

        
3. Lokalizacja nazw geograficznych (PRNG) oraz Słowniki państwowe

        
        
• Nazwa obiektu geograficznego z rejestru PRNG

        https://services.gugik.gov.pl/uug/?request=GetLocation&location=Las Mierzei

        
• Słownik miejscowości przypisanych do wybranej gminy (TERYT)

        https://services.gugik.gov.pl/uug?request=GetCity&teryt=141207

        
• Słownik zarejestrowanych ulic w miejscowości (SIMC)

        https://services.gugik.gov.pl/uug?request=GetStreet&simc=0668956

        
• Lista punktów adresowych przy wybranej ulicy (SIMC + ULIC)

        https://services.gugik.gov.pl/uug/?request=GetAddresses&simc=0668956&ulic=00470

        
• Lista punktów w miejscowości dla obszarów bez nazwanych ulic (SIMC)

        https://services.gugik.gov.pl/uug/?request=GetAddresses&simc=0002750

        
• Słownik dróg głównych

        https://services.gugik.gov.pl/uug?request=GetRoads
